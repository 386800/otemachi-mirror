アセスメント（個別採点・添削）

Output Program

学習の最終工程は、
第三者に提出して評価されること。

Assessmentは、教材（Input）で学んだ内容を架空企業・架空数値のケースで実際にアウトプットし、担当実務家による100点満点の採点・レビュー・改善フィードバックを受け取る、教材購入者限定の月額プログラムです。日本語・非同期・マイページ完結。

対象：ゴールド／プラチナ教材の購入者（Assessment Proはゴールド以上、Assessment Eliteはプラチナ限定）。教材プランとは別契約・別料金です。

教材で学んだうえで「自分のアウトプットが実務水準に達しているか」を確かめたい方のためのサービスです。

Assessmentで目指す状態本番前に実務家の評価と次の改善課題を得ている

事業計画や投資分析を、数字のつながった資料にしたい

Assessmentで目指す状態数値の因果関係が通った、提出できる資料を作成できる

次の方・用途は対象外です

  • 教材を一度も学んでいない完全な未準備の状態でのご利用（教材との同時申込は可能です）
  • 実在案件の業務代行（ケースはすべて架空企業・架空数値です）
  • 投資助言・財務助言・税務助言・法務助言、転職斡旋
  • 勤務先や第三者の機密情報を含む資料のレビュー

学習から到達までのロードマップ

  1. UNDERSTAND教材で理解する
  2. BUILD架空ケースで自力構築
  3. SUBMITExcel・回答資料を提出
  4. VALIDATE採点・弱点特定（Pro）
  5. REFINE／RESUBMIT修正・再提出・再採点（Elite）
  6. EXPLAIN選考・実務で説明できる

ProVALIDATEまで。採点・項目別コメント・模範解答で弱点を特定し、修正方針を自分で立てられる状態へ。

EliteREFINE／RESUBMITまで。指摘を反映した再提出物を再採点し、修正後の完成度まで確認します。

ご利用の流れ

  1. 教材プランを購入（対象：Pro=ゴールド以上／Elite=プラチナ。同時申込・差額アップグレードも可）
  2. Assessmentを契約（マイページから申込・決済。Stripe・月額。同時申込の場合は教材の決済完了後に自動で進みます）
  3. ケース課題が配布される（架空企業・架空数値。1契約期間＝1か月にPro 1ケース／Elite 2ケース）
  4. Excel・回答資料を提出（最終提出でロックされます）
  5. 採点・返却（担当実務家が採点。Pro 原則5営業日以内／Elite 原則2営業日以内）
  6. 確認質問（採点結果へ Pro 2問／Elite 3問まで）
  7. 再提出・再採点（Eliteのみ）（指摘を反映して再提出し、1契約期間に1回まで再採点）

よくある質問

Assessmentだけを契約できますか？
いいえ。対象の教材プラン（Pro=ゴールド以上／Elite=プラチナ）をご購入の方のみお申し込みいただけます。教材プランをまだお持ちでない方は「まとめて申し込む」から教材と同時にお申し込みいただけます（お支払いは教材分とAssessment分の2件に分かれます）。
教材プランの料金にAssessmentは含まれますか？
いいえ。教材プラン（買い切り）とAssessment（月額）は別契約・別料金です。Assessmentを契約しなくても、購入した教材はすべてご利用いただけます。
「1契約期間」とは何ですか？
1か月（1回の請求期間）を指します。契約期間ごとにケース枠（Pro 1ケース／Elite 2ケース）が付与され、未使用分は翌契約期間に繰り越されません。
誰がレビューしますか？
