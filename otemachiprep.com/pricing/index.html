  • 大手町プレップについて

INPUT × OUTPUT

学んで終わらない。
実務で通用するアウトプットまで。

大手町プレップは、教材で知識と実務の型を身につける「Input」と、ケースを解いて提出し、実務経験者による採点・フィードバックで仕上げる「Output」を一つの学習体系として提供します。知っているだけの状態から、自分で組み、分析し、判断し、説明できる状態を目指します。

PEファンド、投資銀行、FAS・M&A、FP&A、CFO・経営企画などの選考・実務に加え、事業会社やスタートアップにおける資金調達、事業計画・予算策定、融資申請用の事業計画、資金繰り、プロジェクトファイナンスなど、幅広いファイナンス課題に応用できるアウトプット力を養成します。

  • 100点満点の個別スコアリング
  • ファイナンス実務経験者による直接レビュー
  • 日本語・非同期で提出から返却まで完結
まず教材プランを選ぶ Assessment Pro／Eliteを見る

教材プラン（Input・買い切り）と Assessment（Output・月額）は別契約・別料金です。教材プランの料金に Assessment は含まれません。Assessment 単体ではご契約いただけません。

INPUT × OUTPUT

教材で学び、Assessment で実力を測る。

教材（Input）で身につけた知識と型を、架空企業・架空数値のケース課題で実際にアウトプット。ファイナンス実務経験者（PEファンド・投資銀行部門・FAS・プロジェクトファイナンスの経験者によるレビュー体制）が100点満点で採点し、項目別コメント・模範解答・改善課題を返却します。

Assessment Pro 月額29,800円／Elite 月額49,800円（税込・最低3か月）。教材プラン購入者限定・別契約。教材プランとの同時申込も可能です。

アセスメントの詳細を見る このページの料金詳細へ

InputからOutputまでの学習フロー

教材で学び、作って提出し、採点・フィードバックを受けて改善する。この繰り返しで仕上げます。

  1. LEARN

    体系的に学ぶ

    教材で知識・理論・実務手順を体系的に学ぶ。

  2. BUILD

    自分で作る

    Excelモデル、分析、事業計画、回答資料等を自分で作る。

  3. SUBMIT

    提出する

    架空企業・架空数値を用いたケース課題を提出する。

  4. REVIEW & SCORE

    評価を受ける

    担当実務家が評価基準に沿って直接レビューし、100点満点で採点する。

  5. IMPROVE

    改善する

    項目別コメント、模範解答、改善課題を確認し、必要に応じて再提出する。

  6. OUTPUT

    使える状態へ

    自分で組み、分析し、判断根拠を説明できる状態へ近づく。

↻Input → Output の一方通行では終わりません。採点結果で可視化された弱点は、該当する教材に戻って補強し、次のケースや再提出（Elite）で確認する——この改善サイクルを回すことを前提に設計しています。

教材販売で終わらない、評価と改善までのファイナンス教育

PDFやExcel教材を読むだけでは、本当に実務で使えるかどうかは判断できません。大手町プレップでは、教材による体系的な学習に加え、実際に成果物を作成・提出し、採点基準に基づくスコア、項目別コメント、模範解答、次に取り組むべき改善課題を受け取れる仕組みを提供します。

INPUT

体系的なInput

日本の実務文脈に合わせたPDF、Excel、ケーススタディ、模範解答。基礎から順に積み上げる累積型カリキュラム。

ASSESSMENT

実務家によるAssessment

正解・不正解だけでなく、前提、数式、構造、分析、判断、説明まで確認。課題領域に応じた担当実務家が直接レビューします。

OUTPUT

改善可能なOutput

弱点を数値とコメントで可視化し、次の学習・再提出につなげる。学んだ内容を実際に使える能力へ変換します。

実務を知る専門家が、提出物を直接レビュー

大手町プレップでは、複数の専門人材によるレビュー体制を構築し、課題の領域に応じた担当者が成果物を直接確認します。数式の正確性だけでなく、前提条件、モデル構造、分析の深さ、意思決定の妥当性、説明の一貫性まで評価します。

  • PEファンドまたは投資銀行部門（IBD）での勤務経験を持つメンバー
  • FASでの勤務経験を持つ現役公認会計士
  • 大手メガバンクでプロジェクトファイナンスに従事した経験を持つメンバー

※ 各提出物は、課題領域に応じた担当実務家がレビューします（全レビュアーによる共同採点ではありません）。

申込みから改善までの流れ

Stage 1（教材）は今日から始められます。Stage 2（Assessment）は任意のタイミングで追加できます。

  1. 1

    会員登録・メール認証

    メールアドレスで会員登録し、確認メールのリンクで認証します。

  2. 2

    教材プランを選んで決済

    サイト内でクレジットカード決済（Stripe）。カード番号は当サイトでは保持しません。決済完了後すぐ、全教材がマイページに表示されます。

  3. 3

    教材で学ぶ（Input）

    PDFテキストとExcel（Blank／Guide／Completed／Checks）をダウンロードして学習。購入済み教材は期間終了後も継続利用でき、6か月後の更新は任意です。

  4. 4

    （任意）Assessment を申し込む

    マイページの「アセスメント」から Pro／Elite を選択。お申し込み時に保有プランとログイン状態を確認のうえ、月額決済（Stripe）で開始します。教材プランの選択時に「まとめて申し込む」を選んだ場合は、教材の決済完了後に自動でこのお手続きへ進みます。

  5. 5

    ケース課題に取り組み、提出する（Output）

    契約期間ごとに配布される架空企業のケース課題を、Excelモデルや回答資料として作成し、マイページから提出します。

  6. 6

    採点・フィードバックを受け取る

    担当実務家がレビューし、Pro は原則5営業日以内、Elite は原則2営業日以内に、スコア・項目別コメント・模範解答を返却します。

  7. 7

    確認質問・再提出・弱点補強

    採点結果への確認質問（Pro 2問／Elite 3問まで）や、Elite の再提出・再採点を活用。教材に戻って弱点を補強し、次のケースへ進みます。

よくある質問

教材プラン（Input）について

単品購入はできますか？

現在は単品販売を行っていません。各講座は、シルバープラン・ゴールドプラン・プラチナプランのいずれかに含まれる形で提供しています。

購入した教材は6か月後に使えなくなりますか？

いいえ。購入は月額課金ではなく買い切りです。購入時点でプランに含まれる教材と、購入後6か月間に追加された新教材・改訂版は、6か月経過後もマイページから継続してダウンロード・利用できます。

更新は必須ですか？

いいえ、任意です。自動更新・自動課金はありません。期限が近づくと更新のご案内をお送りします。更新すると、そこから次の6か月間に公開される対象教材・改訂版にアクセスできます。更新しない場合でも、それまでに付与された教材とバージョンはそのまま使えます。

上位プランへ変更できますか？

できます。マイページの「プラン・アップグレード」から、差額のみで上位プランにアップグレードできます。

支払い方法は？

クレジットカード決済（Stripe）に対応しています。カード情報は Stripe 社の決済基盤で安全に処理され、当サイトがカード番号を保持することはありません。

領収書は発行できますか？

マイページの「注文履歴・領収書」から、宛名を指定して発行できます（税込金額・内消費税10%表記）。

返金はできますか？

デジタルコンテンツの性質上、ダウンロード後の返金は原則お受けできません。ファイル破損等の不具合は再配布またはご返金で対応します。

法人名義で購入できますか？

可能です。領収書の宛名を法人名で発行できます。ご要望はお問い合わせください。

Assessment（Output）について

Assessmentだけを契約できますか？

いいえ。Assessment は教材プラン購入者限定のオプションです。Pro はゴールド／プラチナ購入者、Elite はプラチナ購入者のみお申し込みいただけます。なお、教材プランをまだお持ちでない方は、料金ページの「まとめて申し込む」から教材プランと Assessment を同時にお申し込みいただけます（お支払いは教材分と Assessment 分の2件に分かれます）。

教材プランの料金にAssessmentは含まれますか？

いいえ。教材プラン（買い切り）と Assessment（月額）は別契約・別料金です。Assessment を契約しなくても、購入した教材はすべてご利用いただけます。

誰がレビューしますか？

複数の専門人材によるレビュー体制を構築しており、PEファンドまたは投資銀行部門での勤務経験を持つメンバー、FASでの勤務経験を持つ現役公認会計士、大手メガバンクでプロジェクトファイナンスに従事した経験を持つメンバーなどが在籍しています。各提出物は、課題領域に応じた担当実務家がレビューします。

実在企業の資料や機密情報を提出できますか？

できません。ケース課題はすべて架空企業・架空数値で構成されており、勤務先の資料・実在企業の機密情報・第三者の秘密情報を含む成果物の提出は禁止しています。

ビデオ通話はありますか？

ありません。提出から採点・フィードバック・確認質問まで、すべてマイページとメールで完結する非同期型のサービスです。

返却まで何営業日かかりますか？

Pro は原則5営業日以内、Elite は原則2営業日以内に返却します（土日祝・年末年始・事前に告知した休業日を除く）。

再提出できますか？

Elite は1契約期間に1回まで再提出・再採点が可能です。Pro に再提出はありません（採点結果への確認質問は Pro でも可能です）。

合格や融資承認を保証しますか？

いいえ。特定の企業・ファンド・銀行への合格や内定、資金調達・融資の承認、投資成果、スコアの向上を保証するものではありません。

Assessmentはコンサルティングサービスですか？

いいえ。Assessment は学習成果を評価・フィードバックするファイナンス教育・評価サービスです。個別案件に対する投資助言・財務助言・税務助言・法務助言、およびコンサルティングや業務の代行は行いません。
